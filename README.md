# Paper.js Project

A minimal [Paper.js](http://paperjs.org/) starter built with [Vite](https://vitejs.dev/).

## Getting started

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Scripts

- `npm run dev` — start the dev server with hot reload
- `npm run build` — build for production into `dist/`
- `npm run preview` — preview the production build

## Structure

- `index.html` — entry page with a full-screen `<canvas>`
- `src/main.js` — Paper.js setup and demo sketch (animated sine wave, click to spawn fading circles)
- `src/style.css` — full-screen canvas styling
